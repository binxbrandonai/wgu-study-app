## TROUBLESHOOTING

### "My ZIP file is too large (>50MB)"
**Solution:** You probably included node_modules. Run the `create-gumroad-package.sh` script - it excludes unnecessary files.

### "Gumroad won't let me publish"
**Common issues:**
- Missing product description
- No file uploaded
- No price set
- No cover image

**Fix:** Check each field has content.

### "No one is buying"
**Likely causes:**
- Not enough visibility (share in more groups)
- Price too high (test $37 vs $47)
- Product description unclear (simplify value prop)
- Images not compelling (improve visuals)

**Solution:** Share in 5+ communities, get 100+ views before judging.

### "Customer says download link doesn't work"
**Fix:** Gumroad sends download link automatically. Check:
- Customer's spam folder
- Gumroad settings (email delivery enabled)
- Resend link manually from Gumroad dashboard
